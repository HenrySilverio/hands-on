# Caixa de entrada da curadoria

Largue aqui qualquer fonte de conhecimento de negócio: PDF, docx, um `.md` com o texto colado
de uma conversa do Teams, ou um arquivo de uma linha com a URL (ex.: uma resolução do Bacen).

Nenhum formato é rejeitado nesta porta. Atrito aqui mata a adesão.

Depois, no Copilot app, peça ao agente **po-curar-fonte** para processar. Ele devolve um PR com
o arquivo normalizado, a citação literal, o link e a interpretação em seção separada.

**Nada em `inbox/` é considerado verdade.** É matéria-prima até passar por revisão humana.
